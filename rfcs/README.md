# RFCs

Internal design notes and implementation plans. Not part of the published docs site — they live outside `docs/` on purpose so they're invisible to the SSG.

Use this directory for proposals, refactor plans, and architecture audits that are too rough or too internal to ship to `docs.repowire.io`. Once a plan is realized, either fold the relevant bits into `docs/` (as a guide or design note) or leave the RFC here as a historical record.
