# Start

Get Repowire running, connect your first agents, and route a cross-repo ask.

- [Install](install.md) — checksum-verified native release installer.
- [Setup](setup.md) — `repowire setup` detects your agents and wires hooks, MCP, plugins, and services.
- [First ask](first-ask.md) — open two sessions and route a question.
- [Compare](compare/index.md) — understand where Repowire fits next to adjacent tools.

Total time: ~5 minutes. Requires macOS or Linux and tmux; Python is not required.
