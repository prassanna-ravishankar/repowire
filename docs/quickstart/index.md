# Quickstart

Get repowire running and route your first cross-repo ask.

- [Install](install.md) — uv, pipx, pip, or the interactive installer.
- [Setup](setup.md) — `repowire setup` detects your agents and wires hooks.
- [First ask](first-ask.md) — open two sessions and route a question.

Total time: ~5 minutes. Requires macOS or Linux, Python 3.10+, and tmux.
