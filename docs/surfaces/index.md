# Control surfaces

How humans drive the mesh. Each surface registers as a peer and uses the same `ask` / `notify` / `broadcast` primitives as agents.

- [Web dashboard](dashboard.md) — Next.js UI at `localhost:8377/dashboard`.
- [Telegram bot](telegram.md) — phone-side control via Telegram.
- [Slack bot](slack.md) — Socket Mode bot in a Slack workspace.
